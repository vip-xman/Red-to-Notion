## 项目说明

本扩展旨在支持将小红书网页版帖子一键收藏到Notion，包含以下核心功能：
- 提取帖子标题
- 提取帖子正文内容  
- 提取帖子中的所有图片
- 整合内容并保存到Notion数据库

## 🔄 UX优化计划 - 基于用户反馈

### 📋 用户反馈的问题

**当前问题分析：**
1. **登录状态不清晰**：用户登录后，插件界面状态没有变化，仍显示"一键登录"按钮
2. **页面授权流程不合理**：页面访问权限配置应该在登录后的插件中管理，而不是在登录过程中
3. **过时配置方式**：手动输入Token和Page ID的方式已过时，应该完全移除

### 🎯 重新设计的用户交互流程

**理想用户路径：**
```
步骤1: 打开插件 → 显示"一键登录Notion"按钮
步骤2: 点击登录 → 跳转Notion授权（基础权限即可）
步骤3: 授权完成 → 回到插件，显示已登录状态
步骤4: 管理页面 → 点击"管理可访问页面"按钮
步骤5: 添加页面 → 选择要添加剪藏权限的页面
步骤6: 剪藏内容 → 从已添加的页面中选择目标页面
```
